# 🌌 3D Solar System Portfolio

> A 3D bilingual portfolio website where each planet in the solar system represents a different section of my personal portfolio.

---

## 🖼️ Overview

This is an interactive 3D portfolio website designed as a solar system — each planet leads to a different section of my portfolio.
It merges creative storytelling with cutting-edge web technologies to create a truly immersive and unique browsing experience.

The website supports two languages (slovak and english) and includes features such as authentication, contact forms, and real-time data fetching.
